# Security Policy

## Supported Versions

We provide security updates and patches for the following versions:

| Version | Supported          |
| ------- | ------------------ |
| 1.x.x   | :white_check_mark: |
| < 1.0.0 | :x:                |

---

## Reporting a Vulnerability

Security is a high priority for FuelFinder Italy. If you discover a security vulnerability or potential issue, please follow these guidelines:

1. **Do not disclose publicly:** Please refrain from opening public GitHub issues or public pull requests disclosing sensitive security details.
2. **Contact Privately:** Report vulnerabilities directly by creating a [Private Security Advisory](https://github.com/Gaetano-Taormina/FuelFinder-Italy/security/advisories/new) via GitHub Security.
3. **Include details:**

   - A clear description of the vulnerability
   - Step-by-step instructions or Proof of Concept (PoC) to reproduce the behavior
   - Impact assessment

4. **Response Timeline:** We will review your report within 48-72 hours, acknowledge receipt, and coordinate a fix and coordinated disclosure.
